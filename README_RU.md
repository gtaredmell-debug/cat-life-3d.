# Cat Life 3D — Android-проект

Это стартовый 3D-прототип на Godot 4.4 для Android (ARM64, Vulkan не требуется: используется Compatibility renderer).

## Что уже есть
- 3D-площадка с дорогами, прудом, деревьями и пятью зданиями;
- управляемый кот с сенсорными кнопками;
- 18 котов-NPC;
- простые действия: погладить, взять на руки, кормить, играть;
- мини-карта;
- базовая смена режима «город / интерьер» (пока демонстрационная).

## Сборка APK без компьютера
1. Создай аккаунт GitHub, если его ещё нет.
2. Создай новый публичный репозиторий, например `cat-life-3d`.
3. Загрузи в него **все файлы и папки из этого архива**, включая скрытую папку `.github`.
4. Открой вкладку **Actions** репозитория.
5. Запусти workflow **Build Android APK** кнопкой **Run workflow** (или дождись запуска после загрузки).
6. Открой завершённый запуск, найди раздел **Artifacts** и скачай `CatLife3D-Android-APK`.
7. Распакуй скачанный архив на телефоне и установи APK. Если Android спросит, разреши установку из этого источника.

## Важно
- В этом архиве находится исходный проект, а не готовый APK.
- Для сборки используется GitHub Actions и контейнер Godot CI. Облачная сборка может занять несколько минут.
- Проект — ранний игровой прототип. Геометрия котов и окружения пока процедурная и стилизованная; это не фотореалистичная графика.
- Для публикации в Google Play потребуются отдельные настройки подписи релизной сборки.
